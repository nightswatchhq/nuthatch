Nuthatch 5.0.1 is the first published 5.x release. It is 5.0.0 with one fix to how the release is
built, so everything in the [5.0.0 notes](v5.0.0.md) applies to it: the WASM layer is gone, a
`[screening]` table no longer loads, shipped binaries use fat LTO, and new segments hash differently.

## Why there is no 5.0.0 download

v5.0.0 was tagged and never published. Its aarch64 Linux build was shut down twice during the
fat-LTO link of `nuthatch`, out of memory on the ARM runner, and a release with a missing target
stays a draft. 5.0.1 gives the Linux release runners swap before they build, which changes nothing
the `dist` profile produces (#2008).

## Gated on Lodestar's data

The code is 5.0.0's, which passed the release gate on every production nest (see its notes). This
release's commit carries its own `release-gate/<nest>` statuses from the same gate run against a
Linux `dist` build of it.

## Compatibility and upgrade

As for 5.0.0: replace the binary and restart, after deleting any `[screening]` table. From 5.0.0
it is a binary swap.
