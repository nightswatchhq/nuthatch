Nuthatch 4.12.0 makes the query engine cheaper on view-heavy nests, adds Linux arm64 downloads, and
fixes a shutdown that could hang. There is no storage migration.

## Faster, leaner analytical SQL

Burrmill moves to `19dd795` (#1965, nightswatchhq/burrmill#93):

- A view used inside another repeated view is now shared, not recomputed per use, and each shared
  subquery is planned once.
- "Latest row per key" (`row_number() ... = 1`) is no longer rewritten into a plan slower than the
  window it replaced, and its rewrite no longer loses the partition column (burrmill#89, #90).
- A hash join's build side is compacted before it is probed.

On the BetSwirl stopgap nest's full history (160,802 bets, 2026-10-06, ThinkPad, cold, 20-run p50)
the SDK's `bets` query went from 10.4 s to 5.8 s, and its single-`bet` query, which ran out of memory
at the default 512 MB, now answers in 3.1 s with a 200 MB engine peak. Answers are byte-identical
before and after. Repeated statements are still served from the answer cache in milliseconds.
[#1951](https://github.com/nightswatchhq/nuthatch/issues/1951) stays open for the rest.

## Linux arm64

The default and graph builds now ship for `aarch64-unknown-linux-gnu` (#1963), built natively on
`ubuntu-22.04-arm` with the same glibc 2.35 floor as x86_64 and attested like the others. The install
script picks them up. The container image and the scaled build remain x86_64.

## Fixes

- **SIGTERM no longer hangs while the admin UI is open.** The admin event stream ends when shutdown
  starts, and any connection still open 5 s later is dropped, so a restart cannot wait on a browser
  tab (#1967, #1964). This applies to `dev` and the multi-nest runtime.
- **The `llms.txt` that `init` writes** now says authored views answer on `/sql` by name, and that
  `/queries` lists the queries an operator declared in `mounts.toml`. It previously sent agents to an
  empty `/queries` for their views (#1968, #1966).

## Compatibility and upgrade

Replace the binary and restart. No re-index. To serve GraphQL, use the `nuthatch-graph` download.
Run the release gate on a nest with join-heavy views before rolling it there: the engine's join and
sharing plans changed.
