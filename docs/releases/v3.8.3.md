A runtime now keys a nest's cursor, health and metrics by the route it serves the nest under, so a nest
whose route differs from its name is measured, quarantined and unmounted correctly (#1419, fixes
#1415). `nuthatch emit dune` translates the authored views whose translation into DuneSQL is exact,
and names the rest with the construct that stopped each one (#1409, RFC-0055 S3). A seal-direct backfill
counts the documents it stores in `nuthatch_nest_ipfs_resolved_total` (#1422, fixes #1421).

## Compatibility and upgrade

Replace the binary and restart. **Storage identity, the NID, configuration and sealed segments do not
change.** `Config.route` is `#[serde(skip)]`: the runtime sets it when it builds a nest, it is never
read from or written to `nuthatch.toml`, and it does not enter the content address. Nothing in the store
is keyed by it, webhook cursors included, so an interrupted backfill resumes from its saved watermark as
before. The single-nest `dev` path has no route and is unchanged, and so is a runtime nest whose route
equals its nest's name.

For a runtime nest whose route, its alias or `tenant/alias`, differs from its nest's name:

- **The `nest` label on its `nuthatch_nest_*` series is the route**, where the cursor's series carried
  the nest's name. A dashboard or alert rule that selects such a nest by name must select it by route.
  Two tenants' nests that share a name no longer share one set of series.
- **A mirror's publisher reports under the route of its dataset's first mount**, which is where the
  cursor records `sealed_through`, so publish lag still compares the two.
- **An `entity_fault` alert's `nest` field carries the route.**
- **Unmounting the route stops its cursor and releases its store.** In 3.8.2 the cursor ignored the
  command as not its own, acknowledged it, and kept running with the store open.

**`emit dune` writes more files.** A view that translates exactly now gets its own query beside the
table queries, where 3.8.2 listed every authored view as not emitted. Nothing a nest indexes, stores or
serves changes.

**`nuthatch_nest_ipfs_resolved_total` now counts the documents a seal-direct backfill proves and stores**
(#1422, fixes #1421), as `given_up`, `unverified` and `retries` already did, so a backfilling nest's
count jumps on upgrade.

**Downgrading to 3.8.2 is safe.** Nothing this release changes is persisted. Series return to the
nest's name, and a route whose name differs is again not stopped by unmounting it.

## A runtime keys a nest by its route (#1419)

A runtime serves a nest under a route, but the nest's cursor recorded its metrics and health under the
nest's own name, while `/ready`, the series labels, health and unmount all address it by route. When the
two differed, `/ready` read zeros and nulls, a quarantine landed under a key nothing read, and unmounting
the route left its cursor running. The runtime now stamps the route onto the nest's configuration when
it builds the nest at boot or on a hot mount, and the cursor, its health and its metrics use it.

## `emit dune` translates authored views (#1409)

`nuthatch emit dune` now writes a DuneSQL query for each authored view in `views/*.sql` whose translation
is exact. DuckDB's own parser reads each view, and the query is rendered again from an allowlist of
constructs that return the same result in DuckDB and in Trino. It reads the uploaded tables and
projects `_dec` and `_overflow` with the nest's own expression, so it answers over the uploaded rows
what the nest's view answers, less the unsealed tip.

Every other view is listed under "Not emitted" in the output `README.md`, with the construct that
stopped it: `/`, `avg`, a floating-point literal, `GROUP BY ALL`, `QUALIFY`, `DISTINCT ON`, a window
function, `*` or an unaliased expression in its output, a table function, a call, block or state table,
or a view it reads that was itself refused. One divergence is outside any allowlist: DuckDB answers a
decimal sum past 38 digits, and Trino is documented to raise on that overflow, so such a query should fail
on Dune rather than return a different number. The Trino half of that has not been run.
